# SimpleZapretGUI

Простое приложение для обхода блокировок Discord и YouTube — в одну кнопку, как VPN-клиент.
Графическая оболочка для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
от Flowseal: без консольных окон, батников и ручной настройки. Приложение само скачивает запрет по ссылке выше и подскажет, что делать дальше даже для самых маленьких
Все настройки так же вынесены в графический интерфейс для удобства и контроля

Важно учесть, весь код написан нейронкой, сам я не программист, но задолбали эти батники, захотел красивую оболочку. Все исходники у меня есть, так что обязательно буду обрабатывать обратную связь и выпускать фиксы.

> SimpleZapretGUI — это не VPN: трафик не идёт через чужие серверы, скорость и пинг не страдают.
> Приложение запускает zapret, который обходит блокировки провайдера прямо на вашем компьютере.

## Как начать

1. Запустите установщик и следуйте шагам. На рабочем столе появится ярлык.
2. При первом запуске нажмите **«Установить»** в баннере сверху — приложение само скачает zapret.
3. Нажмите **«Запустить автотест»**. Приложение проверит все стратегии и само выберет ту,
   что лучше всего работает у вашего провайдера.
4. Нажмите на большую кнопку — обход включён.

## Возможности

- **Включение в одну кнопку.** Видно, работает ли обход, какая стратегия и сколько времени.
  Статус виден даже если zapret запущен не приложением — и его можно выключить отсюда.
- **Автотест стратегий.** Проверяет Discord, YouTube и другие сайты для каждой стратегии и
  ставит лучшую первой. Можно проверять и свои сайты из списков.
- **Служба Windows.** По желанию обход включается вместе с Windows, даже без открытого приложения.
- **Списки сайтов.** Добавление и удаление сайтов и IP, свои категории, проверка «попадает ли сайт
  под обход».
- **Редактор стратегий** — для тех, кто хочет собрать свою.
- **Всё из service.bat** — Game Filter, IPSet, фейки, hosts, диагностика, очистка кэша Discord —
  с понятными подсказками.
- **Обновления zapret** проверяются в фоне. При обновлении ваши списки, стратегии и настройки
  сохраняются.
- **Поиск по настройкам** (`Ctrl+F`).

## Частые вопросы

**Windows пишет «Система Windows защитила ваш компьютер».**
Установщик не подписан платным сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

**Антивирус ругается на winws.exe или WinDivert.**
Это известная особенность самого zapret: он работает с сетевым трафиком через драйвер WinDivert,
и антивирусы иногда считают это подозрительным. Добавьте папку `C:\ProgramData\SimpleZapretGUI`
в исключения антивируса.

**Зачем права администратора?**
zapret использует сетевой драйвер WinDivert, а он работает только с правами администратора.
Если включить в настройках «Запускать вместе с Windows», приложение будет стартовать без
запроса прав.

**Обход включён, но Discord или YouTube не работают.**
Запустите автотест — у разных провайдеров работают разные стратегии. Если Discord не грузится,
нажмите «Очистить кэш Discord» на главной. Ещё можно открыть «Сервис» → «Диагностика»:
она найдёт конфликтующие программы (VPN, другие обходы, Adguard) и предложит исправление.

**Как удалить?**
«Параметры Windows» → «Приложения» → SimpleZapretGUI → «Удалить». Деинсталлятор выключит обход,
уберёт службу, драйвер и автозапуск и спросит, удалить ли ваши настройки.

**Нашли ошибку?**
[Создайте issue](../../issues/new/choose) и приложите журнал: «Настройки» → «Папка журналов» → `app.log`.

## Где что хранится

| Путь | Что там |
|---|---|
| `C:\Program Files\SimpleZapretGUI` | само приложение |
| `C:\ProgramData\SimpleZapretGUI\zapret` | скачанный zapret |
| `C:\ProgramData\SimpleZapretGUI\user` | ваши настройки, стратегии, списки, результаты тестов |
| `C:\ProgramData\SimpleZapretGUI\logs` | журналы |

## Для разработчиков

Приложение написано на Python 3 + PySide6 (Qt).

- `run.bat` — запуск из исходников для отладки (сам создаёт окружение; данные и журналы — в `data\`).
- `build.bat` — полная очистка, сборка `SimpleZapretGUI.exe` (PyInstaller) и установщика (Inno Setup 6,
  ставится сам через `winget`). Результат — в `dist-installer\`.
- `installer.bat` — пересобрать только установщик из уже собранной программы.
- `clean.bat` — убрать всё, что осталось после отладки.

**Сборка на GitHub.** При каждом пуше GitHub Actions собирает установщик
(вкладка Actions → артефакт). Тег вида `v1.2.0` автоматически создаёт релиз с установщиком.
